01

Amélioration de l’accessibilité RGAA d’une application web

Banque de France — Stage 2025

Contexte

Au sein de la Banque de France, j'ai participé à la mise en conformité d'une application web avec le Référentiel Général d'Amélioration de l'Accessibilité (RGAA), standard obligatoire pour les organismes publics.

Besoin exprimé

L'application web de la Banque de France ne respectait pas entièrement les critères du RGAA. Il fallait identifier les non-conformités et proposer des corrections pour améliorer l'accessibilité aux personnes en situation de handicap.

Résultats obtenus

Le taux de conformité RGAA de l'application a été significativement amélioré. Plusieurs critères auparavant en échec ont été validés, rendant l'application plus accessible aux utilisateurs en situation de handicap visuel ou moteur.

Technologies utilisées

HTML CSS JavaScript RGAA 4.1 ARIA Git
02

Pôle informatique & gestion du site web

Leclerc Bollène — 2026 — Alternance

Contexte

Au sein du pôle informatique du magasin Leclerc de Bollène, j’ai intégré l’équipe chargée de la gestion des outils informatiques et du site web du magasin.

Besoin exprimé

Le magasin souhaitait maintenir et faire évoluer son site web pour améliorer l’expérience des clients en ligne : mise à jour des contenus, correction de dysfonctionnements et ajout de nouvelles fonctionnalités.

Résultats obtenus

Les mises à jour réalisées ont permis d’améliorer la fiabilité et la lisibilité du site. L’équipe informatique a pu s’appuyer sur les développements effectués pour maintenir une expérience utilisateur cohérente pour les clients du magasin.

Technologies utilisées

HTML CSS JavaScript PHP MySQL Git
